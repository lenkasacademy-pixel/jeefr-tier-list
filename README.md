## Tier list — how it works

All 27 JEE Main Maths chapters start in the tray at the bottom. Put each one
into S / A / B / C / D yourself:

- **Tap** a chapter, then **tap a tier** — or **drag** it across.
- Tap a placed chapter and tap another tier to move it.
- **List** shows the finished tier list in full chapter names, with a copy button.
- **Reset** clears the board. **Hide bar** hides the footer before recording.

Tiles and label text resize themselves to whatever screen the page is on, and
shrink further as a tier fills up, so nothing is cut off.

Built as a single self-contained HTML file — no build step, no dependencies
beyond the Fredoka webfont.
